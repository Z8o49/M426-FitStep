# Definition of Done und Abnahme · Sprint 0

Diese Liste bei der tatsächlichen Prüfung des Projektstands ausfüllen.

## Definition of Done

- [ ] Der enthaltene Umfang entspricht der Sprint-Beschreibung.
- [ ] `npm ci` und der App-Start funktionieren in der Testumgebung.
- [ ] `npm run verify` läuft erfolgreich.
- [ ] Die folgenden Bedienprüfungen wurden durchgeführt.
- [ ] Änderungen und offene Punkte sind nachvollziehbar beschrieben.

## Manuelle Abnahme

- [ ] Dashboard, Pedometer und Settings lassen sich über die Tab-Leiste öffnen.
- [ ] Der aktive Tab ist erkennbar.
- [ ] Text und Schaltflächen sind auf einem kleinen Smartphone lesbar.
- [ ] Inhalt und Tab-Leiste überdecken sich nicht.
- [ ] Die Oberfläche bleibt innerhalb der sicheren Bildschirmbereiche.

## Tatsächliche Prüfung festhalten

Ergänze beim Prüfen Gerät beziehungsweise Browser, Ergebnis und bei einem Fehler die Schritte zur Reproduktion. Für Review und Retro reichen konkrete Beobachtungen: Was ist fertig, was bleibt offen, was ändern wir beim nächsten Mal?
